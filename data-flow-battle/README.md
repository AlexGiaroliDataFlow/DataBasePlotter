# Data Flow Battle

A self-contained browser battle game about defending a live data pipeline.

Open `index.html` in a browser, or serve the folder with a static web server.

## Controls

- Move: `WASD` or arrow keys
- Fire: space, enter, or hold pointer
- Abilities: `1` Burst, `2` Shield, `3` Reroute
- Pause: `P`

The boss uses the provided photo asset and explodes when defeated.
